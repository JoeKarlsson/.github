# Security policy

This is the default security policy for my repositories. A repo with its own `SECURITY.md` follows that one instead.

## Reporting a vulnerability

Report it privately from the repo's **Security** tab with **Report a vulnerability** (GitHub's private vulnerability reporting). If a repo doesn't offer that, reach me through [joekarlsson.com/contact](https://www.joekarlsson.com/contact/). Please don't open a public issue or pull request for it.

Helpful things to include:

- The repo, and the file or URL involved
- Steps to reproduce, or a proof of concept
- What an attacker could do with it

I maintain these projects by myself, so I can't promise a fixed response time. I'll confirm I got your report, keep you posted while I fix it, and credit you in the advisory if you'd like.

## Supported versions

Only the default branch of an active repo. Archived repos are kept for reference and won't get fixes.

## Testing

Good-faith research that stays within this policy is welcome, and I won't take action against you for it. Don't access data that isn't yours, don't disrupt anything other people use, and give me a reasonable chance to fix a problem before you talk about it publicly.

There's no bug bounty.
